# Документы проекта

Снимок проектной документации на 27 сентября 2026 (рассылка объявлений и ужин
на двоих включены). Эти файлы лежат здесь,
чтобы Claude Code мог их читать: `CLAUDE.md` ссылается на разделы
спецификации, и без неё ссылки ведут в пустоту.

| Файл | О чём | Когда открывать |
|---|---|---|
| `01-контекст-проекта.md` | что за продукт, статус, принципы, словарь | первым в любой новой сессии |
| `02-спецификация-ядра.md` | формулы, допуски, алгоритм подбора, схема БД | любые правки в `core.py` и `planner.py` |
| `03-деплой.md` | пошаговый вывод бота на Railway | бот уже развёрнут; открывать при правках окружения и переменных |
| `06-база-рецептов.md` | состав базы, покрытие, пробелы | работа с `data/recipes.csv` |
| `08-промпт-для-поиска-рецептов.md` | запрос новой партии блюд | пополнение базы |
| `10-сборник-рецептов.md` | все 83 карточки: состав, граммовка, приготовление | готовка, сверка состава, правка рецепта |
| `11-памятка-составителю-рецептов.md` | требования и форматы для того, кто придумывает блюда | заказ новой партии рецептов |
| `12-объявления.md` | тексты рассылок и правила отправки | обновили бота и надо сказать об этом людям |
| `13-описание-для-рекламы.html` | что есть в боте, какими словами это описывать, чего обещать нельзя | рекламные материалы, тексты для канала, лендинг |

`13` лежит в HTML, а не в markdown: из него печатается PDF, и вёрстка — часть
документа. Пересобрать после правки:

```bash
/opt/pw-browsers/chromium-1194/chrome-linux/chrome --headless --no-sandbox \
  --no-pdf-header-footer --print-to-pdf=Порция-описание-продукта.pdf \
  file://$PWD/docs/13-описание-для-рекламы.html
```

Цифры в нём — из замеров, а не из головы. При обновлении бота пересобирать
обязательно, иначе реклама начнёт обещать не то, что есть.

Проверки в репозитории: `scripts/check_data.py` — формат данных и сверка
сборника с базой, `scripts/coverage.py` — покрытие по сетке профилей.
Запускать в таком порядке после любой правки данных.

## Где источник истины

Полные версии живут в проекте claude.ai — там же документы 00 (правила работы),
04 (предложение партнёру), 05 (снимок кода) и 07 (исходник `CLAUDE.md`).
Их здесь нет: 04 коммерческий, 05 дублирует сам код, 00 и 07 описывают работу
в claude.ai, а не в репозитории.

`06` здесь сокращён: поштучные таблицы всех 83 позиций убраны, потому что они
дублировали бы `data/recipes.csv`. По КБЖУ источник истины — CSV, по составу и
приготовлению — `10-сборник-рецептов.md`.

`10` собран скриптом из авторских карточек, но сам скрипт в репозиторий не
входит: дальше сборник правится руками, прямо в markdown. Если меняете КБЖУ —
поменяйте их и в `data/recipes.csv`, иначе бот будет считать по старым.
В сборнике 83 карточки — столько же, сколько авторских рецептов в базе.
В сборнике 21 блюдо партии 1, а в базе их 18 — разбор в разделе «Что не
сходится» в конце сборника.

**Если правите документ здесь — перенесите правку в проект claude.ai, иначе
версии разойдутся.** Обратное тоже верно.
