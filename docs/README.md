# Документы проекта

Снимок проектной документации на 22 сентября 2026. Эти файлы лежат здесь,
чтобы Claude Code мог их читать: `CLAUDE.md` ссылается на разделы
спецификации, и без неё ссылки ведут в пустоту.

| Файл | О чём | Когда открывать |
|---|---|---|
| `01-контекст-проекта.md` | что за продукт, статус, принципы, словарь | первым в любой новой сессии |
| `02-спецификация-ядра.md` | формулы, допуски, алгоритм подбора, схема БД | любые правки в `core.py` и `planner.py` |
| `03-деплой.md` | пошаговый вывод бота на Railway | сейчас это ближайшая задача |
| `06-база-рецептов.md` | состав базы, покрытие, пробелы | работа с `data/recipes.csv` |
| `08-промпт-для-поиска-рецептов.md` | запрос новой партии блюд | пополнение базы |

## Где источник истины

Полные версии живут в проекте claude.ai — там же документы 00 (правила работы),
04 (предложение партнёру), 05 (снимок кода) и 07 (исходник `CLAUDE.md`).
Их здесь нет: 04 коммерческий, 05 дублирует сам код, 00 и 07 описывают работу
в claude.ai, а не в репозитории.

`06` здесь сокращён: поштучные таблицы всех 64 рецептов убраны, потому что они
дублировали бы `data/recipes.csv`. По составу источник истины — CSV.

**Если правите документ здесь — перенесите правку в проект claude.ai, иначе
версии разойдутся.** Обратное тоже верно.
