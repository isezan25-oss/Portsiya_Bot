# Порция

Telegram-бот, который **планирует** питание на день: по полу, возрасту, росту,
весу, активности и цели считает норму калорий и БЖУ и собирает из базы
конкретные блюда с граммовкой.

Не трекер. Трекеры перекладывают работу на человека — найди продукт, взвесь,
внеси, — и их бросают за две недели. Здесь работа сделана заранее: состав
каждого блюда посчитан один раз автором, а система подбирает комбинацию под
конкретного человека.

## Быстрый старт

См. `НАЧНИ-ОТСЮДА.md`. Коротко:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # вставить токен от @BotFather
export BOT_TOKEN=...
python -m app.bot
```

## Состояние

**Бот работает**: развёрнут на Railway, отвечает в Telegram.

- Расчётное ядро, подбор плана, бот на aiogram 3.
- База: 83 позиции, 67 авторских рецептов и 16 продуктов, 12 добавок.
- Покрытие по сетке из 130 профилей — 98,5% (`python3 scripts/coverage.py`).
- Коэффициент активности считается по опросу: шаги, часы на ногах,
  тренировки, физический труд.
- Рецепты приходят в бот из `docs/10-сборник-рецептов.md`, по ним же
  собирается список продуктов с отметками.
- Режим «нет сил»: план только из блюд до 20 минут.
- Защита сборника: три подбора в сутки, план фиксируется после выдачи
  рецептов, журнал выдач и трассировка экземпляров.
- Не сделано: дневник съеденного, разбор свободного текста, напоминания,
  семейный профиль, подписка и оплата.

## Важно

Репозиторий приватный: `data/recipes.csv` содержит неопубликованный авторский
сборник рецептов, который лежит в основе платного продукта.

Это не медицинский сервис. Расчёты справочные и не заменяют консультацию врача.
