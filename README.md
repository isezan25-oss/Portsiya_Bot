# Порция

Telegram-бот, который **планирует** питание на день: по полу, возрасту, росту,
весу, активности и цели считает норму калорий и БЖУ и собирает из базы
конкретные блюда с граммовкой.

Не трекер. Трекеры перекладывают работу на человека — найди продукт, взвесь,
внеси, — и их бросают за две недели. Здесь работа сделана заранее: состав
каждого блюда посчитан один раз автором, а система подбирает комбинацию под
конкретного человека.

## Быстрый старт

См. `НАЧНИ-ОТСЮДА.md`. Коротко:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # вставить токен от @BotFather
export BOT_TOKEN=...
python -m app.bot
```

## Состояние

- Расчётное ядро, подбор плана, бот на aiogram 3 — готовы.
- База: 80 позиций, 64 авторских рецепта и 16 продуктов, 12 добавок.
- Покрытие по сетке из 130 профилей — 100% (`python3 scripts/coverage.py`).
- Не сделано: деплой, дневник съеденного, разбор свободного текста,
  напоминания, витрина подборок, оплата.

## Важно

Репозиторий приватный: `data/recipes.csv` содержит неопубликованный авторский
сборник рецептов, который лежит в основе платного продукта.

Это не медицинский сервис. Расчёты справочные и не заменяют консультацию врача.
